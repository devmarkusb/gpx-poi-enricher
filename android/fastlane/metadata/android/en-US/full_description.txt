GPX POI Enricher: turn Google Maps directions into a routed GPX track and enrich the route with OpenStreetMap points of interest using built-in YAML profiles (camping, food, beaches, playgrounds, and more).

<b>What you can do</b>
• Paste a Maps directions link and build a routed GPX (public OSRM / Nominatim; no API key for defaults)
• Run POI enrichment along a track with configurable profiles from the same YAML set as desktop
• Optionally add evenly spaced split markers
• Edit profiles

<b>Who it is for</b>
Campers, hikers, cyclists, and road-trip planners who already use GPX with Garmin, OsmAnd, or Google My Maps and want the enrich / split / maps-to-GPX pipeline on the go.

<b>Privacy & network</b>
Online steps (geocoding, routing, Overpass) use public endpoints; see the project README for rate limits and attribution. The app does not require an account.
